## Signal classification (detail in the decision doc)

- **§3.5 batch size (WAREHOUSE_REGULAR_BATCH_SIZE=32):** The audit claimed "most shards produce less than one row group." **Partially disproven:** the morpheme tables produce 154 row groups per shard (86,480 / 562), well above 1. But the small tables (analyses, sources) produce only ~5 row groups per shard at ~470 rows each — genuinely sub-row-group territory. Peak RSS is already 50.6 GiB, so raising batch_size risks the §3.10 memory ceiling. → **DEFER** (needs RSS-aware sweep).
- **§3.12 Parquet compaction on merge:** 3 tables (analyses, sources, feature_pattern_counts) have >64 parts AND median part <1 MiB. → **TUNE**.
- **§3.15 analyzer parallelism within a worker:** No scaling data. → **DEFER** (needs hours-long j=1 run).
