3. Produce a full-corpus admission row for the current build (or admit the exact current tuple through ADR 0023) so release qualification evaluates the release candidate, not a stale tuple.
4. Re-run the gate; promote ADR 0039 to Accepted ONLY if every predicate verdict is `pass` from captured evidence.

Do not start these under this plan; open a brainstorming session and a dedicated plan, because each instrument is a substantial, independently-specifiable subsystem.
